## 2. 수정 프롬프트

아래 프롬프트를 위에서부터 하나씩 실행. 한 번에 여러 개를 섞지 않기.

### 프롬프트 1 - 대시보드 라우트 정리

```text
이 프로젝트를 week_04 릴리즈 기준에 맞게 수정해줘.

목표:
- 로그인한 사용자가 `/dashboard`로 이동하면 대시보드가 보여야 해.
- 기존 `/` 화면에서 대시보드 역할을 하던 코드는 유지하되, 라우팅 구조를 명확히 정리해줘.
- 로그인하지 않은 사용자는 로그인 또는 랜딩 화면으로 보내줘.
- 온보딩이 끝나지 않은 사용자는 온보딩 화면으로 보내줘.

작업 기준:
- 기존 컴포넌트와 상태 관리 구조를 최대한 유지해줘.
- 수정 후 `npm run build`로 확인해줘.
- 변경한 파일과 이유를 짧게 정리해줘.
```

### 프롬프트 2 - 린트 설정 수정

```text
현재 `npm run lint`가 ESLint 설정 문제로 실패해.

목표:
- 현재 설치된 ESLint 버전에 맞게 설정 파일을 수정해줘.
- React Hooks 관련 규칙이 정상 적용되게 해줘.
- 코드 스타일 수정이 필요하면 기능 변경 없이 최소 범위로 정리해줘.

확인:
- `npm run lint`
- `npm run build`

완료 후:
- 실패 원인
- 수정한 설정
- 남은 주의점
위 내용을 짧게 정리해줘.
```
